대학 입학 후 본격적으로 프로그래밍을 시작하며 머릿속의 전투 메커니즘을 코드로 구체화하는 일에 집중했습니다. 이론에 머무르지 않고 실제 프로젝트에 뛰어들어 FSM 기반 몬스터 AI, AABB 및 Sphere Overlap을 활용한 프레임 단위 판정 시스템, 데이터 드리븐 파이프라인을 주도적으로 설계했습니다. 호기심으로 시작했던 액션에 대한 열정을 실전 전투 클라이언트 개발 역량으로 탄탄하게 다져나가고 있습니다.

[3학년 1학기: 2D 탑다운 액션 전투 AI 심화 및 데이터 파이프라인 완성]

2D 탑다운 액션 게임 '로그타워'에서 전투 클라이언트 전반을 전담했습니다. 일반 몬스터는 Navigation AI를 적용해 지형 장애물을 자율 회피하며 추적하도록 구현하고, FSM 상태 머신으로 탐색·공격 로직을 모듈화해 신규 몬스터 개발 공수를 30~50% 단축했습니다. 대형 보스 몬스터는 근·중·원거리 다중 센서를 구축해 플레이어와의 거리에 따라 패턴이 유기적으로 변화하도록 설계했습니다. 나아가 AABB 및 Sphere Overlap 기반의 프레임 단위 타격 판정, Raycast2D를 통한 원거리 사선(LOS) 검증 로직을 구축했습니다. 또한 MySQL 마스터 데이터를 JSON(몬스터)과 CSV(아이템)로 이원화 추출하고, Dictionary 캐싱을 통해 런타임에 동적으로 주입하는 데이터 드리븐 환경을 완성하며 확장성 높은 전투 시스템을 구축했습니다.

플레이어의 조작에 즉각 반응하고 타격의 순간이 직관적으로 전달되는 실시간 액션 게임의 손맛에 깊이 매료되어 전투 클라이언트 개발의 길을 선택했습니다. 게임의 몰입감은 정교한 프레임 단위 타격 판정과 피격 시점에 정확히 맞물리는 시각 이펙트의 동기화 등, 전투 로직의 세부 완성도에서 결정된다고 믿습니다.

프로젝트를 진행하며 FSM 기반 몬스터 AI, AABB 및 Overlap 기반 충돌 판정, 오브젝트 풀링과 데이터 드리븐 파이프라인을 직접 구축하며 기획된 전투 경험을 안정적인 코드로 구현하는 역량을 길렀습니다. 유저의 입력이 빈틈없는 상호작용과 역동적인 전투 경험으로 직결될 수 있도록, 전투 시스템의 디테일을 집요하게 검증하고 완성해 내는 클라이언트 프로그래머가 되겠습니다.
